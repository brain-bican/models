    Donor Schema

    The BICAN Donor Metadata schema specifies the metadata relating to donors in BICAN. These metadata reflect the metadata needed to accurately track donors and related entities from the brain banks through the specimen portal.

    URI: https://w3id.org/brain-bican/donor

    Name: Donor
